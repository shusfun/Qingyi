# 0002 版本发布规则

## 背景

轻译与 mistral-gui 的早期发布版本跃升过快，需要重新设定初始版本和后续递增规则。

## 决定

- 两个应用各自以 `0.1.1` 作为当前发布基线，后续各自递增。
- 默认只增加一个补丁版本，例如 `0.1.1` → `0.1.2`。跳过补丁号、提高次版本或主版本，须先取得仓库所有者对目标版本的明确授权。
- 以当前正式 Release 为递增基准。历史发布继续保留，下一次补丁发布是 `0.1.2`。

## 影响

已安装更高版本的用户可下载 `0.1.1`，在原扩展目录覆盖后重新加载。后续补丁沿当前基线更新。

## 依据

仓库所有者于 2026-11-19 指定两仓以 `0.1.1` 初始化，并要求优先发小版本，跳大版本须经本人授权。
