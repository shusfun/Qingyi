阅读与网站

外观和进度显示即时保存，不会中断翻译。

网页上的 × 仅关闭该页面进度条。点击“轻译”打开设置；拖动可在本设备记住位置。

本地缓存

索引、版本、日志和导入暂存均占空间。默认 4 GiB；容量取决于内容。命中缓存不会持久化更新访问时间或 LRU。

存储详情 
进入本地缓存后读取统计，也可点击“刷新统计”。

词库与版本

导入 qingyi-pack-v1 JSONL 或 gzip 容器：首行 manifest，后续每行一个带摘要的 gzip 数据块。完整包与增量包先暂存校验，完成后切换版本；失败时保留旧版。

用户修订

修订优先于词库和模型缓存，每条保留最近 20 版。使用精确原文；含结构占位符的段落须保持占位符。

诊断追踪

追踪扫描、缓存、排队、请求尝试、数据库提交和页面回填。不记录 Key、原文、译文或请求体。第三方内部链路不可观测；没有供应商请求 ID 时标记为不可关联。

按需查询，每页最多 200 条；完整记录通过导出查看。

更新与迁移

手动下载 ZIP 与 SHA-256 后，核对摘要，替换安装目录，再到扩展管理页重新加载。插件不会自动执行下载文件或覆盖本地目录。

从旧版轻译迁移

先打开旧版设置，启用一次性迁移并获得 6 位验证码。Key 通过指定扩展间消息传递，不导出为文件。迁移完成前保留旧扩展；新扩展需重新授权 API 和网站。
